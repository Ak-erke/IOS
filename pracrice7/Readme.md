# My Favorites TableView App

## Overview
My Favorites TableView is an iOS application built with UIKit that displays my favorite items across four categories: Movies, Music, Books, and University Courses. The app demonstrates the use of `UITableView`, custom cells, dynamic heights with Auto Layout, and a clean, user-friendly design.

## Features
- Display favorites in **4 sections**: Movies, Music, Books, Courses
- Custom `UITableViewCell` with:
  - Image view
  - Title label
  - Subtitle label
  - Review label
- Dynamic cell heights using Auto Layout
- Custom section headers with emoji and title
- Clean and simple design

## Technologies Used
- Swift 5
- UIKit
- Storyboard
- Auto Layout
